# ADR-0009 — Мінімізація персональних даних

Статус: accepted (2026-09)

## Контекст
Продукт торкається дітей. Кожне зайве поле — зобов'язання із захисту
і ризик при витоку. Обіцянка надійності включає обережність з PII.

## Рішення
Зберігаємо мінімум: ім'я дитини + контакт батька (телефон та/або
Telegram). Свідомо НЕ збираємо: адреси, дати народження, email
(до тригера ADR-0011), документи, фото.

## Альтернативи (відкинуті)
- «Зібрати про запас» — зобов'язання без потреби.

## Наслідки
- PII живе в payload подій → дампи шифруються client-side (ADR-0006).
- Нове поле з PII — лише через ADR.
- У prod-логах payload подій не друкується цілком; PII в логи не
  потрапляє.

## Для Claude Code
structlog-конфіг у prod не логує event payload. У тестових фікстурах —
вигадані імена/телефони. Жодних реальних даних у репо/фікстурах.
